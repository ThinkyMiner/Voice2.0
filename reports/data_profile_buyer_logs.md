# Data profile: buyer_logs

Experiment `vani-buyer-qty-asks-v1`: primary `bl_success` = any answered call with disposition in ['BL Enriched', 'BL Approved']; window 14 days. Generated by `make profile DATASET=buyer_logs` from the full data (deterministic, no sampling).

**Definitions.** Trigger = a lead's first answered call (§2.6). Baseline p at horizon H = share of triggered leads with an answered call in the primary set between the trigger and trigger + H days (inclusive of the trigger call). Censoring: the denominator for H holds only leads triggered at or before (last ts − H days), so every counted lead had full follow-up.
